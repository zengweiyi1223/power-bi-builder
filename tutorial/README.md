# Codex × Power BI 图文教程

本目录保存已经定稿的五张教程卡片，不改变冻结的 `V0/` 实验产物。

## 当前内容基线

- `xhs/cards.html`：五张卡片的唯一内容源，可直接用浏览器打开。
- `xhs/jpg/`：从卡片源文件导出的 JPG 发布版本。
- `xhs/export-cards.mjs`：使用 Playwright 清理旧 JPG 并重新导出全部卡片。
- `xhs/validate-cards.mjs`：检查卡片页码、图片资源和内容溢出。
- `assets/`：卡片使用的图标，以及保留供后续使用的原始截图素材。

## 五张结构

1. 封面与案例背景。
2. 首次使用需要完成的三项配置。
3. 可复制提示词、三个人工等待点和简单流程。
4. 完整 PBIP 项目交付结构。
5. 最终报表成果与人机边界。

## 内容原则

- 一次性配置与正式生成流程分开说明。
- 明确标注人工应当打开、保存、关闭和重开 Desktop 的节点。
- MCP、PBIP 种子、项目副本和数据路径分别说明。
- 正式副本采用实际业务报表名称，不沿用种子的 `Seed` 名称。
- V0 的验证细节不进入卡片，只保留实际使用所需的操作边界。
- 公开图片不得包含账号、凭据、令牌或不必要的本机信息。

## 本地查看与导出

直接用浏览器打开 `xhs/cards.html`。重新导出时运行 `xhs/export-cards.mjs`；脚本会先删除输出目录中的旧 JPG，再生成当前五张卡片。导出后运行 `xhs/validate-cards.mjs` 检查版面与资源。
