01

设置 Power BI Desktop

文件 → 选项和设置 → 选项

全局 → 预览功能：勾选“Power BI 项目（.pbip）保存选项”“使用 TMDL 格式存储语义模型”“使用增强的元数据格式（PBIR）存储报表”。

全局 → 数据加载 → 时间智能：取消“新文件的自动日期/时间”。

当前文件 → 数据加载 → 时间智能：取消“自动日期/时间”。点击“确定”并重启 Desktop。

02

创建空白 PBIP 种子

新建空白文件，仅保留 Overview；另存为 Power BI 项目（*.pbip）。

将完整项目保存到稳定、可复用的模板目录，例如 <模板库>/power-bi/blank-seed/，不要放在临时目录。

关闭 Desktop 后不再修改种子原件；后续由 Codex 复制整个项目目录。

03

让 Codex 安装并验证 MCP

请安装 Microsoft 官方 Power BI Modeling MCP，放在稳定的用户工具目录并注册到 Codex。需要重启 Codex 时先告诉我。安装后复制空白种子到临时验证目录，明确告诉我打开哪个 .pbip；等我确认已经打开后，再验证 MCP 能否发现、连接并读取模型。不要修改种子原件。

04 / 05·山楂条
交付前最后一步

不要只发送 .pbip
要交付完整项目目录

YourReport/ ├─ YourReport.pbip ├─ YourReport.Report/ ← PBIR 报表页面 │ └─ definition/ └─ YourReport.SemanticModel/ ← TMDL 语义模型 └─ definition/
  • 入口文件、Report 和 SemanticModel 必须保持同级位置。
  • 整个目录一起移动、提交 Git 或发送给使用者。
  • 换电脑后，本地数据路径和凭据可能需要重新绑定。
  • 不要交付缓存、本机设置、自动恢复文件或临时目录。
最常见错误：只发送 `.pbip` 入口文件。缺少另外两个目录，Desktop 无法得到完整报表和模型。
